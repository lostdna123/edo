# PT Indocom Niaga — Website

An Apple-inspired, single-page marketing site for PT Indocom Niaga, a Jakarta-based IT solutions provider (est. 2004).

Plain HTML/CSS/JS — no build step, no dependencies.

## Run locally

```bash
python3 -m http.server 8080
# then open http://localhost:8080
```

(Any static server works, e.g. `npx serve .`.)

## Files

- `index.html` — page content (hero, services, partners, about, contact)
- `styles.css` — styling, animations, responsive layout
- `script.js` — scroll reveal, adaptive nav, mobile menu, contact form (opens the visitor's mail client)

Company details (services, partner tiers, vision/mission, contact info) were gathered from public sources, including indocomniaga.co.id — please verify before publishing.
